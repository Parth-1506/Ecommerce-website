## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Parth-1506/Ecommerce-website.git
```

### Navigate to the Project

```bash
cd Ecommerce-website
```

### Run the Website

Simply open **index.html** in your browser.

Or run it using **VS Code Live Server**.
